# Rush-01: Skyscraper Puzzle Solver (4x4)

A backtracking-based skyscraper puzzle solver written entirely in C, following the strict 42 Norminette coding standards.

## How It Works
The program takes 16 visibility clues corresponding to the 4 sides of the grid (Col Up, Col Down, Row Left, Row Right) and recursively finds a valid 4x4 skyscraper configuration satisfying both Sudoku uniqueness rules and viewpoint constraints.

## Compilation
Compile the source files using:

gcc -Wall -Wextra -Werror *.c -o rush-01
